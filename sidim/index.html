El archivo recibido contiene 200 filas con el mismo correo: eugueruz02@gmail.com. Si usas ese archivo completo, se generarán 200 mensajes para esa dirección. Para enviar a los asistentes, actualiza la columna email con sus correos.

1 · Copia en Thunderbird

Abre un mensaje con Write. Si reutilizas un borrador, elimina sus destinatarios anteriores antes de pegar el nuevo To.

El saludo usa {{name}}. Mail Merge lo reemplaza con el nombre de cada fila. Los botones copian la plantilla con sus variables, aunque la vista previa muestre una persona concreta.
Ver el código HTML para copiar

En el cuerpo vacío del mensaje, abre Insert → HTML…, pega el código y pulsa Insert.

2 · Configura Mail Merge

Desde la ventana del mensaje, abre Tools → Mail Merge.

SourceXLSX
FileBrowse → selecciona larga.xlsx.
SheetnameSheet1. También puedes dejar esta opción desmarcada: es la primera y única hoja.
  1. Activa la casilla Attachments en Mail Merge y pega {{document}} en su campo de texto.
  2. Usa el Browse de esa sección para seleccionar los PDF. Puedes seleccionar todos los certificados de la carpeta a la vez.
  3. El nombre de cada PDF debe coincidir exactamente con la columna document, incluida la extensión .pdf.

No hace falta escribir la carpeta ni la ruta. Seleccionar todos los PDF en este Browse permite que Mail Merge elija el que corresponde a cada fila. El botón Attach de la ventana de redacción agrega adjuntos comunes a todos los mensajes.

3 · Revisa antes de enviar

Para una primera prueba, elige Deliver Mode → Save As Draft y activa Start: 1 y Stop: 1. Pulsa Send en Mail Merge: en este modo se crea un borrador.

Ábrelo en Drafts y comprueba el nombre, el destinatario y el PDF adjunto. Este archivo espera que la primera persona sea Ana Morales.

Para preparar el lote completo, desactiva Start y Stop, cambia a Send Later y pulsa Send. Revisa los mensajes de Local Folders → Outbox. Para enviarlos, usa File → Send Unsent Messages.

Si no aparece Insert → HTML…

Activa Account Settings → Composition & Addressing → Compose messages in HTML format y abre un mensaje nuevo. En Windows, Alt muestra la barra de menús.
